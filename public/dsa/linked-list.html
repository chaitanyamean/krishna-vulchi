Linked List Patterns

Dummy node, fast & slow pointers, in-place reversal — muscle-memory templates with interactive walkthroughs.

How to use this guide

For each pattern: read the plain-English idea → step through the interactive walkthrough → look away and write the template from memory → check yourself → then do the problems.

Key insight for linked lists: Unlike arrays, you can't index into a linked list. All manipulation happens by rewiring next pointers. The patterns here are really just disciplined ways of doing that without losing nodes or creating cycles.

PatternDummy Node

Create a throwaway node before the real head. Point its next to head. Now every node — including the original head — has a predecessor, so you never need an if (head == null) special case. At the end, return dummy.next.

Muscle-memory template — Dummy Node 
ListNode dummy = new ListNode(0, head);   // dummy.next = head
ListNode curr = dummy;

while (curr != null && curr.next != null) {
    if (/* curr.next should be removed */ false) {
        curr.next = curr.next.next;         // skip the node
    } else {
        curr = curr.next;                   // move forward
    }
}

return dummy.next;   // new head (may differ from original)
Why not just move curr forward every time? When you delete curr.next, you must stay at curr — the new curr.next might also need deleting. Only advance when the current node is definitely a keeper.

1. Remove Linked List Elements

Easy Foundational

Remove all nodes from the linked list that have value equal to val.

Why dummy node? The head itself might equal val. Without a dummy you'd need a separate loop to skip leading matches. With a dummy, the loop handles everything uniformly.

Key detail: when curr.next.val == val, skip the node but don't advance curr — the new curr.next might also equal val.

Java solution 
class Solution {
    public ListNode removeElements(ListNode head, int val) {

        ListNode dummy = new ListNode(0, head);
        ListNode curr = dummy;

        while (curr != null && curr.next != null) {
            if (curr.next.val == val) {
                curr.next = curr.next.next;   // skip the target node
            } else {
                curr = curr.next;             // safe to advance
            }
        }

        return dummy.next;
    }
}
// Time: O(n)  Space: O(1)

Trace on [1,2,6,3,4,5,6], val=6:

dummy→1→2→6→3→4→5→6
curr=dummy: next=1 (keep) → curr=1
curr=1: next=2 (keep) → curr=2
curr=2: next=6 (remove) → 2.next=3, stay at curr=2
curr=2: next=3 (keep) → curr=3
curr=3: next=4 (keep) → curr=4
curr=4: next=5 (keep) → curr=5
curr=5: next=6 (remove) → 5.next=null, stay at curr=5
curr=5: next=null → loop ends
return dummy.next → 1→2→3→4→5

2. Delete Nodes From Linked List Present in Array

Easy Common

Given an array nums and a linked list, remove all nodes whose value exists in nums.

Upgrade from problem 1: load nums into a HashSet first so each lookup is O(1) rather than O(n). The dummy node + stay-on-match logic is identical.

Java solution 
class Solution {
    public ListNode modifiedList(int[] nums, ListNode head) {

        ListNode dummy = new ListNode(0, head);
        ListNode curr = dummy;

        Set<Integer> set = new HashSet<>();
        for (int val : nums) {
            set.add(val);
        }

        while (curr != null && curr.next != null) {
            if (set.contains(curr.next.val)) {
                curr.next = curr.next.next;   // skip — might need to skip again
            } else {
                curr = curr.next;             // safe to advance
            }
        }

        return dummy.next;
    }
}
// Time: O(n + m)  Space: O(m)  — n = list length, m = nums length

3. Merge Two Sorted Lists

Easy Very common

Merge two sorted linked lists and return the merged list in sorted order.

Why dummy node? You don't know which list contributes the first node. The dummy gives curr something to attach to from the very start — no special first-node logic needed.

Key detail: after the main loop one list may have remaining nodes — attach the leftover tail directly with curr.next = list1 != null ? list1 : list2.

Java solution 
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {

        ListNode dummy = new ListNode(0);
        ListNode curr = dummy;

        while (list1 != null && list2 != null) {
            if (list1.val < list2.val) {
                curr.next = list1;
                list1 = list1.next;
            } else {
                curr.next = list2;
                list2 = list2.next;
            }
            curr = curr.next;
        }

        // Attach remaining tail (at most one list is non-null)
        curr.next = (list1 != null) ? list1 : list2;

        return dummy.next;
    }
}
// Time: O(n + m)  Space: O(1)

4. Swap Nodes in Pairs

Medium Common

Swap every two adjacent nodes and return the head. You must swap the nodes themselves, not just their values.

Why dummy node? The first pair swap changes the head. The dummy acts as the stable predecessor so curr.next = swap2 works identically for every pair including the first.

Rewiring order — draw this out once:
1. swap1.next = swap2.next — point swap1 past swap2
2. swap2.next = swap1 — swap2 now leads the pair
3. curr.next = swap2 — attach the pair to the chain
4. curr = swap1 — advance curr to the tail of the swapped pair

Java solution 
class Solution {
    public ListNode swapPairs(ListNode head) {

        ListNode dummy = new ListNode(0, head);
        ListNode curr = dummy;

        while (curr.next != null && curr.next.next != null) {

            ListNode swap1 = curr.next;
            ListNode swap2 = curr.next.next;

            swap1.next = swap2.next;   // 1. detach swap2 from rest
            swap2.next = swap1;        // 2. swap2 now points to swap1
            curr.next  = swap2;        // 3. attach swapped pair
            curr = swap1;              // 4. move past the pair
        }

        return dummy.next;
    }
}
// Time: O(n)  Space: O(1)

5. Swapping Nodes in a Linked List

Medium Common

Swap the values of the k-th node from the beginning and the k-th node from the end.

Pattern: fast & slow pointers — no dummy needed since we're swapping values, not rewiring nodes.

Trick: advance fast to the k-th node and save it as first. Then walk fast to the last node while slow walks from the head in parallel — when fast.next == null, slow is exactly at the k-th from the end.

Java solution 
class Solution {
    public ListNode swapNodes(ListNode head, int k) {

        ListNode fast = head;
        ListNode slow = head;

        // Advance fast to the k-th node from the start
        for (int i = 1; i < k; i++) {
            fast = fast.next;
        }
        ListNode first = fast;   // k-th from start

        // Walk fast to the end; slow mirrors it from head
        while (fast.next != null) {
            fast = fast.next;
            slow = slow.next;
        }
        // slow is now the k-th node from the end

        int temp = first.val;
        first.val = slow.val;
        slow.val = temp;

        return head;
    }
}
// Time: O(n)  Space: O(1)

6. Remove Duplicates from Sorted List II

Medium Common

Delete all nodes that have duplicate numbers — the duplicated value itself must also be removed, leaving only distinct numbers.

Why dummy node? The head itself might be a duplicate and need to be removed entirely.

Two-pointer twist: use prev (starts at dummy) and curr (starts at head). When curr starts a duplicate run, fast-forward curr to the last duplicate, then prev.next = curr.next skips the whole block. Only advance prev when the value is unique.

Java solution 
class Solution {
    public ListNode deleteDuplicates(ListNode head) {

        ListNode dummy = new ListNode(0, head);
        ListNode prev = dummy;
        ListNode curr = head;

        while (curr != null) {

            // Detect start of a duplicate run
            if (curr.next != null && curr.val == curr.next.val) {

                // Fast-forward curr to the last node of this value
                while (curr.next != null && curr.val == curr.next.val) {
                    curr = curr.next;
                }

                // Bypass the entire duplicate block; keep prev in place
                prev.next = curr.next;

            } else {
                // Unique value — safe to advance prev
                prev = prev.next;
            }

            curr = curr.next;
        }

        return dummy.next;
    }
}
// Time: O(n)  Space: O(1)

// Trace: 1→2→3→3→4→4→5
// curr=1 unique → prev→1, curr→2
// curr=2 unique → prev→2, curr→3
// curr=3, next=3 → dup run → fast-forward to last 3 → prev.next=4, curr→4
// curr=4, next=4 → dup run → fast-forward to last 4 → prev.next=5, curr→5
// curr=5 unique → prev→5, curr→null
// Result: 1→2→5

PatternFast & Slow Pointers

Two pointers move through the list at different speeds — slow advances one step at a time, fast advances two. When fast reaches the end, slow is at the midpoint. If a cycle exists, the two pointers will eventually collide inside it.

Muscle-memory template — Fast & Slow 
ListNode slow = head;
ListNode fast = head;

while (fast != null && fast.next != null) {
    slow = slow.next;        // 1 step
    fast = fast.next.next;   // 2 steps
}
// When loop ends: slow is at the middle (or inside a cycle)
Why fast != null && fast.next != null? fast.next.next dereferences two levels. We must guard both: fast != null before accessing fast.next, and fast.next != null before accessing fast.next.next.

Must-know questions

7. Middle of the Linked List

Easy Foundational

Return the middle node of a linked list. For even-length lists, return the second middle node.

Why it works: fast moves twice as fast as slow. When fast hits the end, slow is exactly halfway through. For even-length lists (fast == null exits), slow lands on the second of the two middle nodes — which is what LeetCode expects.

Odd (5 nodes): fast reaches the last node (fast.next == null), slow is at node 3. ✓
Even (6 nodes): fast reaches null (fast == null), slow is at node 4 (second middle). ✓

Java solution 
class Solution {
    public ListNode middleNode(ListNode head) {

        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.next != null) {
            fast = fast.next.next;
            slow = slow.next;
        }

        return slow;
    }
}
// Time: O(n)  Space: O(1)

8. Linked List Cycle

Easy Very common

Return true if the linked list has a cycle.

Why it works (Floyd's algorithm): if a cycle exists, fast will eventually lap slow inside the cycle and they will point to the same node. If there's no cycle, fast reaches null first.

Key detail: check slow == fast after moving both pointers — otherwise the initial position (both at head) triggers a false positive.

Java solution 
class Solution {
    public boolean hasCycle(ListNode head) {

        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.next != null) {
            fast = fast.next.next;
            slow = slow.next;

            if (slow == fast) {   // same node reference, not just same value
                return true;
            }
        }

        return false;
    }
}
// Time: O(n)  Space: O(1)

9. Linked List Cycle II — Find the Start

Medium Common

Return the node where the cycle begins, or null if there is no cycle.

Two-phase approach:

Phase 1 — find meeting point: run fast & slow as usual until they collide inside the cycle.
Phase 2 — find cycle start: reset slow to head, keep fast at the meeting point, then advance both one step at a time. The node where they meet again is the cycle entry.

Why phase 2 works (the math): let F = distance from head to cycle start, C = cycle length. At the meeting point, slow has travelled F + a steps and fast has travelled F + a + nC steps (n full laps more). Since fast = 2 × slow: F + a + nC = 2(F + a) → F = nC − a. So walking F steps from head and F steps from the meeting point both land at the cycle start.

Java solution 
class Solution {
    public ListNode detectCycle(ListNode head) {

        ListNode slow = head;
        ListNode fast = head;

        // Phase 1: Find meeting point inside the cycle
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;

            if (slow == fast) {
                // Phase 2: Reset slow to head, move both 1 step at a time
                slow = head;
                while (slow != fast) {
                    slow = slow.next;
                    fast = fast.next;
                }
                return slow;   // cycle start node
            }
        }

        return null;   // no cycle
    }
}
// Time: O(n)  Space: O(1)

10. Remove Nth Node From End of List

Medium Very common

Remove the n-th node from the end of the list and return its head.

Combines dummy node + gap technique: both pointers start at dummy. Advance secondPointer by n steps to open a gap of exactly n. Then walk both until secondPointer.next == null — at that point firstPointer is sitting just before the target node.

Why start both at dummy? If the target is the head (n == list length), firstPointer needs to stay at dummy so firstPointer.next = firstPointer.next.next correctly removes the head.

Java solution 
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {

        ListNode dummy = new ListNode(0, head);
        ListNode firstPointer  = dummy;
        ListNode secondPointer = dummy;

        // Open a gap of n between the two pointers
        for (int i = 0; i < n; i++) {
            secondPointer = secondPointer.next;
        }

        // Walk both until secondPointer reaches the last node
        while (secondPointer.next != null) {
            secondPointer = secondPointer.next;
            firstPointer  = firstPointer.next;
        }

        // firstPointer is just before the node to remove
        firstPointer.next = firstPointer.next.next;

        return dummy.next;
    }
}
// Time: O(n)  Space: O(1)

// Example: 1→2→3→4→5, n=2  (remove 4th node = value 4)
// After gap: secondPointer at node 2, firstPointer at dummy
// Walk: secondPointer→3, firstPointer→1
//       secondPointer→4, firstPointer→2
//       secondPointer→5, firstPointer→3  (secondPointer.next=null, stop)
// firstPointer.next = firstPointer.next.next → 3.next = 5
// Result: 1→2→3→5
