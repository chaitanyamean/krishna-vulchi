FoundationArrays

Everything else in this guide is built on top of arrays, so get comfortable with in-place manipulation first — it's the skill examiners quietly check before anything fancier.

Muscle-memory template — in-place overwrite (fast/slow pointer) Used whenever you must shrink or rearrange an array without extra space. 
int slow = 0;
for (int fast = 0; fast < arr.length; fast++) {
    if (/* arr[fast] should be kept */ true) {
        arr[slow] = arr[fast];
        slow++;
    }
}
// slow is now the new logical length

Must-know questions

1. Move Zeroes

EasyVery common

Given an array, move all 0s to the end while keeping the relative order of the non-zero elements, in-place.

Clue: "in-place", "maintain relative order" → same-direction two pointers.

Java solution 
public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            int temp = nums[slow];
            nums[slow] = nums[fast];
            nums[fast] = temp;
            slow++;
        }
    }
}
// Time: O(n)  Space: O(1)

2. Rotate Array (by k steps, right rotation)

MediumVery common

Rotate nums to the right by k steps, in-place, O(1) extra space.

Clue: "rotate in-place" → the reversal trick: reverse the whole array, then reverse each half.

Java solution 
public void rotate(int[] nums, int k) {
    int n = nums.length;
    k %= n;
    reverse(nums, 0, n - 1);
    reverse(nums, 0, k - 1);
    reverse(nums, k, n - 1);
}

private void reverse(int[] nums, int i, int j) {
    while (i < j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
        i++; j--;
    }
}
// Time: O(n)  Space: O(1)

Example: [1,2,3,4,5,6,7], k=3 → reverse all → [7,6,5,4,3,2,1] → reverse first 3 → [5,6,7,4,3,2,1] → reverse last 4 → [5,6,7,1,2,3,4].

3. Best Time to Buy and Sell Stock

EasyVery common

One pass, one buy + one sell, maximize profit.

Clue: "one transaction, maximize profit" → track the minimum price seen so far as you scan once.

Java solution 
public int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE;
    int maxProfit = 0;
    for (int price : prices) {
        minPrice = Math.min(minPrice, price);
        maxProfit = Math.max(maxProfit, price - minPrice);
    }
    return maxProfit;
}
// Time: O(n)  Space: O(1)

4. Majority Element

EasyCommon

Find the element that appears more than n/2 times. (Boyer–Moore voting algorithm.)

Clue: "more than n/2 times", O(1) space required → pair up a candidate against every other element; it can't lose.

Java solution 
public int majorityElement(int[] nums) {
    int count = 0, candidate = 0;
    for (int num : nums) {
        if (count == 0) candidate = num;
        count += (num == candidate) ? 1 : -1;
    }
    return candidate;
}
// Time: O(n)  Space: O(1)

PatternTwo Pointers

Two indices move through the array (or string) instead of nested loops. It replaces an O(n²) brute force with O(n). There are two flavors:

  • Opposite ends — one pointer starts at index 0, the other at the end, and they move toward each other. Needs a sorted array (or a symmetric structure like a string for palindromes).
  • Same direction (fast/slow) — both start at 0; the fast pointer scouts ahead, the slow pointer marks where to write next. Used for in-place compaction (see Arrays above).

Interactive: opposite-ends walkthrough

Muscle-memory template — opposite ends 
int left = 0, right = arr.length - 1;
while (left < right) {
    int sum = arr[left] + arr[right];
    if (sum == target) {
        // found it
        break;
    } else if (sum < target) {
        left++;   // need a bigger sum
    } else {
        right--;  // need a smaller sum
    }
}

Must-know questions

1. Two Sum II — Input Array Is Sorted

EasyVery common

Return 1-indexed positions of the two numbers that add up to target (array is sorted ascending).

Java solution 
public int[] twoSum(int[] numbers, int target) {
    int left = 0, right = numbers.length - 1;
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) return new int[]{left + 1, right + 1};
        else if (sum < target) left++;
        else right--;
    }
    return new int[]{-1, -1};
}
// Time: O(n)  Space: O(1)

2. Container With Most Water

MediumVery common

Given heights of vertical lines, find two lines that together with the x-axis form the container holding the most water.

Clue: width shrinks as pointers move inward, so always move the pointer at the shorter line — keeping the shorter one can never help.

Java solution 
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1, max = 0;
    while (left < right) {
        int width = right - left;
        int h = Math.min(height[left], height[right]);
        max = Math.max(max, width * h);
        if (height[left] < height[right]) left++;
        else right--;
    }
    return max;
}
// Time: O(n)  Space: O(1)

3. 3Sum

MediumVery common

Find all unique triplets that sum to zero.

Clue: sort first, then fix one number and run the opposite-ends two-pointer on the rest. Skip duplicates carefully.

Java solution 
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();
    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue; // skip dup anchors
        int left = i + 1, right = nums.length - 1;
        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];
            if (sum == 0) {
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                while (left < right && nums[left] == nums[left + 1]) left++;
                while (left < right && nums[right] == nums[right - 1]) right--;
                left++; right--;
            } else if (sum < 0) left++;
            else right--;
        }
    }
    return result;
}
// Time: O(n^2)  Space: O(1) extra (excluding output)

4. Remove Duplicates from Sorted Array

EasyCommon

Remove duplicates in-place from a sorted array so each element appears once; return the new length.

Clue: in-place + sorted → same-direction fast/slow pointers.

Java solution 
public int removeDuplicates(int[] nums) {
    int slow = 1;
    for (int fast = 1; fast < nums.length; fast++) {
        if (nums[fast] != nums[fast - 1]) {
            nums[slow] = nums[fast];
            slow++;
        }
    }
    return slow;
}
// Time: O(n)  Space: O(1)

PatternSliding Window

A specialization of two pointers for contiguous ranges. Instead of recomputing a sum/count for every subarray (O(n·k) or O(n²)), you slide a window and update the running result incrementally — O(n).

  • Fixed size — the window width k never changes; you add one element on the right and drop one on the left every step.
  • Variable size — the window grows by moving right, and shrinks from left only when it breaks some condition.

Interactive: fixed-size window walkthrough

Maximum sum of any subarray of size k = 3, on [2, 1, 5, 1, 3, 2].

Click "Next step" to slide the window.
Muscle-memory template — fixed window 
int windowSum = 0;
for (int i = 0; i < k; i++) windowSum += arr[i];   // build first window
int maxSum = windowSum;
for (int i = k; i < arr.length; i++) {
    windowSum += arr[i] - arr[i - k];   // add new right, drop old left
    maxSum = Math.max(maxSum, windowSum);
}
Muscle-memory template — variable window 
int left = 0;
for (int right = 0; right < arr.length; right++) {
    // 1. expand: fold arr[right] into your running state

    while (/* window is currently invalid */ false) {
        // 2. shrink: remove arr[left] from state, then left++
        left++;
    }

    // 3. window [left, right] is valid here — update the answer
}

2. Longest Substring Without Repeating Characters

MediumVery common

Find the length of the longest substring with no repeated characters.

Clue: "longest substring that satisfies X" → variable window; shrink whenever a repeat shows up.

Java solution 
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> lastSeen = new HashMap<>();
    int left = 0, maxLen = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (lastSeen.containsKey(c) && lastSeen.get(c) >= left) {
            left = lastSeen.get(c) + 1;   // jump left past the repeat
        }
        lastSeen.put(c, right);
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
// Time: O(n)  Space: O(min(n, charset))

3. Minimum Window Substring

HardVery common

Find the smallest substring of s that contains every character of t (with multiplicity).

Clue: "smallest window that satisfies X" → expand until valid, then shrink as far as possible while it stays valid — the classic dual-loop variable window.

Java solution 
public String minWindow(String s, String t) {
    if (s.isEmpty() || t.isEmpty()) return "";
    Map<Character, Integer> need = new HashMap<>();
    for (char c : t.toCharArray()) need.merge(c, 1, Integer::sum);

    Map<Character, Integer> window = new HashMap<>();
    int left = 0, required = need.size(), formed = 0;
    int bestLen = Integer.MAX_VALUE, bestLeft = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        window.merge(c, 1, Integer::sum);
        if (need.containsKey(c) && window.get(c).intValue() == need.get(c).intValue()) {
            formed++;
        }
        while (formed == required) {
            if (right - left + 1 < bestLen) {
                bestLen = right - left + 1;
                bestLeft = left;
            }
            char lc = s.charAt(left);
            window.put(lc, window.get(lc) - 1);
            if (need.containsKey(lc) && window.get(lc) < need.get(lc)) {
                formed--;
            }
            left++;
        }
    }
    return bestLen == Integer.MAX_VALUE ? "" : s.substring(bestLeft, bestLeft + bestLen);
}
// Time: O(n)  Space: O(charset)

4. Longest Subarray with Sum ≤ K

MediumCommonNot on LeetCode

Non-negative integers only. Find the length of the longest contiguous subarray whose sum is at most k.

Java solution 
public int longestSubarraySumAtMostK(int[] arr, int k) {
    int left = 0, sum = 0, maxLen = 0;
    for (int right = 0; right < arr.length; right++) {
        sum += arr[right];
        while (sum > k) {
            sum -= arr[left];
            left++;
        }
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
// Time: O(n)  Space: O(1)

Note: this "shrink while invalid" shape only works cleanly when all values are non-negative — that's why it doesn't apply directly once negatives are allowed (that's Prefix Sum + HashMap territory instead).

for (int i = 0; i < n; i++) {
    prefix[i + 1] = prefix[i] + arr[i];

// sum of arr[l..r] inclusive:
int rangeSum = prefix[r + 1] - prefix[l];
Muscle-memory template — prefix sum + hashmap (count subarrays with sum = k) Works even with negative numbers, where sliding window breaks down. 
Map<Integer, Integer> prefixCount = new HashMap<>();
prefixCount.put(0, 1);   // empty prefix
int sum = 0, count = 0;
for (int num : arr) {
    sum += num;
    count += prefixCount.getOrDefault(sum - k, 0);
    prefixCount.merge(sum, 1, Integer::sum);
}

Must-know questions

1. Range Sum Query — Immutable

EasyFoundational

Design a class that answers many sumRange(left, right) queries efficiently.

Java solution 
class NumArray {
    private int[] prefix;
    public NumArray(int[] nums) {
        prefix = new int[nums.length + 1];
        for (int i = 0; i < nums.length; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
    }
    public int sumRange(int left, int right) {
        return prefix[right + 1] - prefix[left];
    }
}
// Build: O(n)   Query: O(1)

2. Subarray Sum Equals K

MediumVery common

Count how many contiguous subarrays sum to exactly k. Array can contain negatives.

Clue: "count subarrays with sum = k" + negatives allowed → prefix sum + hashmap, not sliding window.

Java solution 
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> prefixCount = new HashMap<>();
    prefixCount.put(0, 1);
    int sum = 0, count = 0;
    for (int num : nums) {
        sum += num;
        count += prefixCount.getOrDefault(sum - k, 0);
        prefixCount.merge(sum, 1, Integer::sum);
    }
    return count;
}
// Time: O(n)  Space: O(n)

3. Product of Array Except Self

MediumVery common

Return an array where each index holds the product of all other elements — without division, O(1) extra space (excluding output).

Clue: this is prefix product from the left combined with suffix product from the right, computed in two passes over the same output array.

Java solution 
public int[] productExceptSelf(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    result[0] = 1;
    for (int i = 1; i < n; i++) {
        result[i] = result[i - 1] * nums[i - 1];   // prefix product
    }
    int suffix = 1;
    for (int i = n - 1; i >= 0; i--) {
        result[i] *= suffix;                        // fold in suffix product
        suffix *= nums[i];
    }
    return result;
}
// Time: O(n)  Space: O(1) extra

PatternKadane's Algorithm

A single-pass dynamic-programming trick for "best contiguous subarray" problems: at every index, decide whether to extend the running subarray or start fresh from here.

Interactive: step through the classic example

arr = [-2, 1, -3, 4, -1, 2, 1, -5, 4] — find the maximum sum contiguous subarray.

Click "Next step" to run Kadane's, one element at a time.
Muscle-memory template At each step: "does adding me help the running streak, or am I better off alone?" 
int maxSoFar = arr[0];
int maxEndingHere = arr[0];
for (int i = 1; i < arr.length; i++) {
    maxEndingHere = Math.max(arr[i], maxEndingHere + arr[i]);
    maxSoFar = Math.max(maxSoFar, maxEndingHere);
}
return maxSoFar;

Must-know questions

1. Maximum Subarray

MediumVery common

The template above, verbatim. Answer for the example is 6, from subarray [4, -1, 2, 1].

2. Maximum Product Subarray

MediumCommon

Same idea, but for products a negative number can flip a very small (very negative) running product into the new maximum — so you must track the running min as well as the running max.

Clue: "product" + negatives allowed → track both running max and running min, swap them when you hit a negative number.

Java solution 
public int maxProduct(int[] nums) {
    int maxProd = nums[0], minProd = nums[0], result = nums[0];
    for (int i = 1; i < nums.length; i++) {
        int num = nums[i];
        if (num < 0) {
            int temp = maxProd;
            maxProd = minProd;
            minProd = temp;
        }
        maxProd = Math.max(num, maxProd * num);
        minProd = Math.min(num, minProd * num);
        result = Math.max(result, maxProd);
    }
    return result;
}
// Time: O(n)  Space: O(1)

3. Maximum Sum Circular Subarray

MediumCommon

The array wraps around — the best subarray may cross the end back to the start.

Clue: "circular" → the wrap-around case equals total sum − minimum subarray sum. Run Kadane's twice: once for the normal max, once (inverted) for the min.

Java solution 
public int maxSubarraySumCircular(int[] nums) {
    int total = 0;
    int maxSum = nums[0], curMax = 0;
    int minSum = nums[0], curMin = 0;
    for (int num : nums) {
        curMax = Math.max(curMax + num, num);
        maxSum = Math.max(maxSum, curMax);
        curMin = Math.min(curMin + num, num);
        minSum = Math.min(minSum, curMin);
        total += num;
    }
    if (maxSum < 0) return maxSum;              // all elements negative
    return Math.max(maxSum, total - minSum);
}
// Time: O(n)  Space: O(1)
